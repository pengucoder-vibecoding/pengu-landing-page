# Prompts

One file per build step, named `NN-short-title.md`. Suggested structure:

```markdown
## Prompt
(the exact prompt)

## Result
(what the AI produced, in one or two lines)

## Fixes
(what was wrong and how it was corrected by hand)
```

Files are added as the template is built. Do not add prompts that contain private URLs, keys or personal data.
